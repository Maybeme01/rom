# 🐍 Queen Rory - Web Python IDE

محرر أكواد وبيئة تطوير تفاعلية بلغة بايثون شبيهة بـ **Visual Studio Code**، مبنية بالكامل باستخدام **HTML, CSS, JavaScript**، وتعمل 100% داخل المتصفح بدون الحاجة إلى أي سيرفر خلفي عبر تقنية **Pyodide (WebAssembly)**.

---

## 🌟 المميزات الرئيسية (Key Features)

1. **واجهة شبيهة بـ VS Code مع بساطة وسرعة فائقة:**
   - شريط جانبي (Activity Bar & Sidebar) قابل للطي والتكبير/التصغير.
   - تبويبات للملفات المفتوحة (Tabs) مع مسار الملفات (Breadcrumbs).
   - نافذة كونسول/تيرمينال سفلية (Dockable Terminal) لعرض المخرجات والأخطاء.
   - شريط حالة سفلي (Status Bar) يعرض سطر ومكان المؤشر وحالة بايثون والـ Git.

2. **تعديل الثيمات (Themes):**
   - يدعم 7 ثيمات شهيرة مع تغيير فوري لكامل الواجهة ومحرر Monaco:
     - **VS Code Dark+** (الافتراضي)
     - **VS Code Light+** (الفاتح)
     - **Dracula**
     - **Monokai Pro**
     - **One Dark Pro**
     - **GitHub Dark**
     - **Cyberpunk Neon**

3. **مساعدة ذكية وإكمال تلقائي للأكواد (IntelliSense & Autocomplete):**
   - محرك **Monaco Editor** (نفس محرك VS Code الرسمي).
   - إكمال تلقائي لدوال بايثون الأساسية (Built-in functions).
   - قوالب جاهزة (Snippets) مثل: `main`, `def`, `class`, `try/except`, `with open`, `listcomp`.
   - اقتراحات استيراد المكتبات الشائعة (`math`, `sys`, `os`, `json`, `random`, إلخ).

4. **أكاديمية وشروحات بايثون التفاعلية (Python Academy):**
   - قسم تعليمي متكامل يحتوي على 12 درساً مشروحاً باللغتين العربية والإنجليزية.
   - يغطي الأساسيات: المتغيرات والطباعة، النصوص، الشروط، الحلقات، القوائم والقواميس، الدوال، البرمجة كائنية التوجه (OOP)، معالجة الأخطاء والملفات.
   - شروحات مفصلة للمكتبات الأساسية في بايثون: `math`, `random`, `datetime`, `json`, `requests`, `matplotlib`, `numpy`.
   - زر **▶ تشغيل في المحرر** بنقرة واحدة لتجربة الكود فوراً ورؤية النتائج مباشرة.

5. **تيرمينال وموجه أوامر طبيعي متكامل (Interactive CLI Terminal & REPL):**
   - يدعم كامل أوامر النظام: `cd`, `pwd`, `ls` / `dir`, `touch`, `mkdir`, `rm`, `mv`, `cp`, `cat`, `echo`, `clear`, `whoami`, `date`.
   - تنقل حقيقي بين المجلدات والمشاريع (`cd 33`, `cd ..`).
   - وضع بايثون التفاعلي `python` (Interactive REPL `>>>`) لكتابة وتجربة أسطر الكود لحظياً.
   - دعم سجل الأوامر عبر الأسهم (↑ و ↓) والإكمال التلقائي لأسماء الملفات والمجلدات عبر زر **Tab**.
   - دعم كامل لألوان ANSI لعرض المخرجات الملونة مثل القلوب واللافتات والرسائل التحذيرية.

6. **تثبيت حزم ومكتبات بايثون الذكي (Smart pip Package Manager):**
   - تثبيت سريع لأي حزمة متوافقة مع Pyodide و PyPI.
   - تصحيح تلقائي للأخطاء الإملائية الشائعة في أسماء الحزم (مثل `requsts` -> `requests`).
   - تنبيهات واضحة وشروحات للمكتبات التي تتطلب برامج نظام محلية مثل `nmap` أو `scapy` مع اقتراح البدائل المتاحة في المتصفح.

7. **دعم استثنائي لشاشات اللمس والآيباد والجوال (iPad & Mobile Support):**
   - شريط تنقل سفلي مرن للأجهزة اللوحية والهواتف الذكية.
   - درج جانبي متحرك (Off-canvas Drawer) مع خلفية معتمة.
   - شريط أزرار افتراضية لكتابة الرموز البرمجية الصعبة على اللمس مثل (`Tab`, `:`, `( )`, `[ ]`, `{ }`, `""`, `=`, `def`, `if`, `#`).

8. **تطبيق ويب تقدمي (PWA - Progressive Web App):**
   - إمكانية تثبيت الموقع كبرنامج مستقل على جهاز الكمبيوتر بنظام ويندوز أو ماك، أو كتطبيق على شاشة الآيباد والأندرويد.

9. **خيارات الحفظ (محلياً وعلى السحابة / GitHub):**
   - **الربط المباشر بمجلدات الكمبيوتر (Native PC Folder Editing):** فتح مجلد حقيقي من جهازك والتعديل عليه وحفظه مباشرة في قرصك الصلب عبر File System Access API.
   - **الحفظ التلقائي المحلي:** يتم حفظ جميع الملفات والتعديلات تلقائياً في المتصفح (LocalStorage).
   - **تصدير واستيراد ZIP:** تنزيل المشروع بالكامل بضغطة زر واحدة.
   - **الحفظ السحابي على GitHub:**
     - خيار **1-Click Gist**: حفظ واسترجاع المشروع في ثوانٍ على GitHub Gist بنقرة زر.
     - خيار **Repository Sync**: رفع ودفع (Commit & Push) الملفات مباشرة إلى مستودعك على GitHub مع رسالة الـ Commit واسم الفرع (Branch)، أو استنساخ (Clone) المشروع.

## 🚀 كيفية رفع الموقع على GitHub Pages وتشغيله أونلاين

الموقع مبني بالكامل كـ Static Web Application، لذا يمكنك رفعه على GitHub واستضافته مجاناً على **GitHub Pages** بكل سهولة:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل على حسابك في [GitHub](https://github.com) واضغط **New Repository**.
2. سمّ المستودع مثلاً: `pycode-studio` أو `web-python-ide`.
3. اجعل المستودع عاماً (Public) واضغط **Create repository**.

### الخطوة 2: رفع الملفات عبر Git
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع ونفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "Initial commit of Queen Rory IDE"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك و `REPO_NAME` باسم المستودع).*

### الخطوة 3: تفعيل GitHub Pages
1. ادخل إلى صفحة المستودع في GitHub واضغط على تبويب **Settings**.
2. من القائمة الجانبية اليسرى اختر **Pages**.
3. تحت خيار **Build and deployment**:
   - Source: اختر **Deploy from a branch**.
   - Branch: اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. انتظر دقيقة واحدة، وسيظهر لك رابط موقعك المباشر في أعلى الصفحة:
   `https://USERNAME.github.io/REPO_NAME/`

## 💻 التشغيل المحلي على جهازك (Local Run)

يمكنك تشغيله محلياً بأي من الطرق التالية:
1. **عبر بايثون:**
   ```bash
   python -m http.server 8000
   ```
   ثم افتح المتصفح على: `http://localhost:8000`
2. **عبر إضافة Live Server في VS Code:**
   - انقر بالزر الأيمن على `index.html` واختر **Open with Live Server**.

## 🔑 كيفية الحصول على GitHub Token للحفظ السحابي
1. في GitHub، ادخل إلى **Settings** > **Developer Settings** > **Personal access tokens** > **Tokens (classic)**.
2. اضغط **Generate new token (classic)**.
3. حدد صلاحية `repo` وصلاحية `gist`.
4. انسخ الرمز والصقه داخل خانة **GitHub Authentication** في الشريط الجانبي داخل الموقع واضغط **Save Credentials**.
